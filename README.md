# RSNA STR Pulmonary Embolism Detection

An end-to-end pipeline for the [RSNA STR Pulmonary Embolism Detection](https://www.kaggle.com/competitions/rsna-str-pulmonary-embolism-detection) challenge (Kaggle, 2020): find pulmonary embolism on every slice of a CT pulmonary angiogram, and predict nine labels for each series. The project rebuilds a solution from scratch after the competition and scores it with late submissions.

Work in progress.
